# Объединение двух независимых источников данных

В эксперименте использованы два открытых источника научных данных:

- **arXiv API** — идентификаторы, названия, аннотации и даты публикаций.
- **Semantic Scholar API** — дополнительные сведения, включая количество цитирований.

Для проверки выбраны три публикации из основного аналитического проекта.

Данные загружались отдельно и соединялись методом **LEFT JOIN** по полю `arxiv_id`.

## Результаты

- Получено из arXiv: **3 записи**.
- Получено из Semantic Scholar: **1 запись**.
- После LEFT JOIN: **3 записи**.
- Успешно сопоставлено: **1 запись**.
- Без дополнительных данных Semantic Scholar: **2 записи**.

Для двух запросов Semantic Scholar вернул ошибку **HTTP 429** (ограничение частоты обращений). Поэтому отсутствие данных в итоговой таблице не означает, что соответствующие публикации отсутствуют в Semantic Scholar.

## Файлы

- `01_arxiv.csv` — сведения первого источника.
- `02_semantic_scholar.csv` — сведения второго источника.
- `03_joined.csv` — результат соединения.
- `04_summary.json` — статистика эксперимента.
- Блокнот `.ipynb` — код получения и объединения данных.

Этот эксперимент демонстрирует самостоятельное соединение двух API на небольшой выборке. Он **не означает**, что основной корпус из 140 576 публикаций был повторно собран из двух API.
